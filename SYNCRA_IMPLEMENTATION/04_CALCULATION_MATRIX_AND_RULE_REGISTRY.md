# SYNCRA — مصفوفة الحسابات الـ 14 ونموذج سجل القواعد (Calculation Matrix & Rule Registry)

> **المبدأ الهندسي:** لا كود حسابي صلب (No Hardcoded Equations). يتم تسجيل القواعد ومخرجاتها في سجل معزول `rule_registry` و `rule_formula_candidate` مع إبقائها غير مفعلة (`implementation_autorisee = false`) حتى يصدر الاعتماد القانوني (N1).

---

## 1. جدول مصفوفة الحسابات الـ 14 (The 14 Calculation Matrix)

وفقاً لوثيقة التأطير الرسمية، هذه هي الحالة الدقيقة لكل عنصر من بنود الحساب:

| المعرف | بند الحساب (Item) | الحالة القانونية | السبب والملاحظات الملزمة |
| :---: | :--- | :---: | :--- |
| **`CALC_01`** | **الراتب الأساسي (Salaire de base)** | ⛔ `BLOQUE` | المعادلة القانونية الدقيقة غير معتمدة رسمياً بعد. |
| **`CALC_02`** | **الغيابات والاقتطاعات (Absences & Déductions)** | ⛔ `BLOQUE` | قاعدة الحساب بالساعات/الأيام ومعدل الخصم غير محددة. |
| **`CALC_03`** | **الأقدمية / تعويض الخبرة المهنية (IEG)** | ⛔ `BLOQUE` | السلم التدريجي (Barème) والنسب بحاجة لمصادقة N1. |
| **`CALC_04`** | **الساعات الإضافية (Heures Supplémentaires)** | ⛔ `BLOQUE` | نسب الزيادة وحدود الساعات لم تُحسم نصوصها. |
| **`CALC_05`** | **وعاء الضمان الاجتماعي (Assiette SS)** | ⛔ `BLOQUE` | تحديد العناصر الخاضعة والمعفاة لم يكتمل قانونياً. |
| **`CALC_06`** | **اشتراك الضمان الاجتماعي أجراء (SS Salariale)** | ⚠️ `CIBLE_CONDITIONNELLE` | صيغة مرشحة (9%)؛ **غير مفعلة بالإنتاج** لحين حسم الوعاء والتقريب. |
| **`CALC_07`** | **اشتراك الضمان الاجتماعي أرباب العمل (SS Patronale)** | ⚠️ `CIBLE_CONDITIONNELLE` | صيغة مرشحة (25%)؛ **غير مفعلة بالإنتاج** لحين حسم الوعاء والتقريب. |
| **`CALC_08`** | **اشتراك أرباب العمل لعقود ANEM** | ⚠️ `CIBLE_CONDITIONNELLE` | معلقة على قرار CNAS والتحقق من سريانه قانونياً. |
| **`CALC_09`** | **الوعاء الخاضع للضريبة (Assiette IRG)** | ⛔ `BLOQUE` | لم يتم حسم قواعد الخصم ومطابقتها للمادة 128 من قانون الضرائب. |
| **`CALC_10`** | **الضريبة على الدخل الإجمالي الجارية (IRG Courant)** | ⛔ `BLOQUE` | خوارزمية جدول الضريبة الكامل وتخفيضات أصحاب الهمم معلقة. |
| **`CALC_11`** | **ضريبة المتأخرات والمستحقات السابقة (IRG Rappels)** | ⛔ `BLOQUE` | آلية التقسيط والـ 10% بحاجة لفتوى ومصادقة نهائية. |
| **`CALC_12`** | **العطل المدفوعة وتعويض الإجازات (Congés)** | ⛔ `BLOQUE` | معادلة احتساب يوم الإجازة وطريقة المقارنة معلقة. |
| **`CALC_13`** | **تصفية الحساب النهائي (STC)** | ⛔ `BLOQUE` | شروط إنهاء العلاقة والتعويضات المستحقة قيد الدراسة. |
| **`CALC_14`** | **صافي الدفع وتكلفة صاحب العمل (Net & Coût)** | ⛔ `BLOQUE` | صيغة التجميع معلقة على اكتمال البنود السابقة وحساب صندوق الخدمات (FOS). |

## 2. بنية شجرة القواعد المجردة (Declarative JSON AST)

لتجهيز النظام لاستيعاب القواعد فور اعتمادها دون إعادة بناء الكود، تم تصميم نمط الشجرة البرمجية المجردة (AST - Abstract Syntax Tree) ككائنات JSON معيارية:

```json
{
  "rule_code": "CALC_06_SS_SAL",
  "ast_version": "1.0.0",
  "status": "CIBLE_CONDITIONNELLE",
  "implementation_autorisee": false,
  "legal_source_ref": "Loi 83-11 modifiée et complétée",
  "legal_article_ref": "Art. 15",
  "valid_from": "2024-01-01",
  "valid_to": null,
  "inputs": [
    { "name": "ASSIETTE_SS", "type": "CURRENCY", "required": true }
  ],
  "rounding": {
    "policy": "HALF_UP",
    "precision": 2,
    "currency": "DZD"
  },
  "expression_tree": {
    "operator": "MULTIPLY",
    "left": { "type": "VARIABLE", "name": "ASSIETTE_SS" },
    "right": { "type": "CONSTANT", "value": "0.09" }
  }
}
```

### مزايا هذا النمط:
1. **الانعزال التام عن منطق التطبيق:** يمكن تحديث نسبة الضمان الاجتماعي دون الحاجة لـ Rebuild أو Deploy للتطبيق ككل.
2. **قابلية التدقيق والتحقق التلقائي (Linting & Dry-run):** يمكن لمفسر القواعد فحص الشجرة بحثاً عن أي متغيرات مفقودة أو سياسات تقريب غير محددة وإيقاف المعالجة مسبقاً.
3. **تتبع الاعتماديات (Dependency DAG):** منع الاعتماديات الدائرية (Circular Dependencies) بين البنود.
